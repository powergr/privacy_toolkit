How Can We Help?

Project QRE is an open-source, local-first privacy initiative focused on secure file encryption, password vault protection, and permanent data destruction tools. Whether you are a security researcher, a developer, or an everyday user, we welcome your feedback.

Security & Vulnerability Disclosure

Security is our highest priority. If you are a security researcher and believe you have found a cryptographic flaw, a memory leak (failure to zeroize), or a vulnerability in our Tauri backend, please contact us immediately.

We value responsible disclosure and will work with you to patch the vulnerability before public disclosure. You can use the form on this page or open a private security advisory on our GitHub repository.

Before You Ask (FAQ)

I lost my Master Password. Can you recover my files?

No. QRE is a "Zero-Knowledge" tool. Your Master Key is generated locally and never leaves your device. If you lose your password and your Recovery Code, your data is mathematically unrecoverable. We cannot bypass AES-256-GCM.

How do I report a bug or request a tool?

The best way to request new features or report non-critical bugs is by opening an Issue on our official GitHub repository. This allows the community to track and contribute to the fix.

Do you collect telemetry or analytics?

The QRE Privacy Toolkit desktop and mobile apps collect absolute zero telemetry. The app is entirely offline-first, only making external requests if you explicitly check for software updates or use the HIBP Breach Checker.
