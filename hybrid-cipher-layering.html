The Technology Behind the Lock

In the era of quantum computing, traditional encryption methods face an existential threat. QRE Locker addresses this by implementing a Hybrid Cipher Architecture. Instead of relying on a single algorithm, we combine the speed and reliability of classical symmetric encryption with the cutting-edge security of post-quantum key encapsulation.

1. The "Dual Lock" Strategy

Every file encrypted by QRE Locker is protected by two distinct cryptographic layers:

  • Classical Layer (AES-256-GCM): We use the Advanced Encryption Standard (AES) with a 256-bit key in Galois/Counter Mode (GCM). This provides military-grade confidentiality and ensures data integrity (you know if the file was tampered with).
  • Post-Quantum Layer (ML-KEM-1024): We wrap the AES session key using Module-Lattice-Based Key-Encapsulation Mechanism (formerly Kyber). This algorithm is selected by NIST as the primary standard for resisting attacks from future quantum computers.

2. How It Works (The Encryption Flow)

When you click "Lock", the following process happens instantly:

  1. Ephemeral Key Generation: The app generates a brand new, random AES-256 session key and a fresh Kyber-1024 keypair specifically for this file.
  2. Data Encryption: The file content is compressed (Zstd) and then encrypted using the AES session key.
  3. Key Encapsulation: The AES session key is encapsulated using the Kyber public key. This "capsule" is stored in the file header.
  4. Key Wrapping: The Kyber private key (needed to open the capsule) is encrypted using your Passphrase (and Keyfile, if used).

This means that even if a quantum computer breaks one layer in the future, the other layer remains secure. An attacker would need to break both distinct mathematical problems to read your data.

3. Stateless & Decentralized Key Management

Unlike complex enterprise systems that require a central key server ("Vault"), QRE Locker uses a Stateless Architecture.

All the cryptographic information needed to decrypt the file is stored inside the file header itself, protected by your Passphrase. This makes QRE Locker ideal for long-term archival and offline storage. You don't need to maintain a database or worry about losing a key server; as long as you remember your passphrase (and have your Keyfile), you can decrypt your data anywhere, forever.

4. Integrity & Authentication

Encryption is useless if an attacker can modify your file without you knowing. QRE Locker uses Authenticated Encryption (AEAD). The file header contains a cryptographic validation token.

When you attempt to unlock a file, the app instantly verifies your password against this token before processing the data. If the password is wrong, or if the file header has been corrupted or tampered with by a single bit, the operation halts immediately, protecting you from malicious payloads.

Performance: Built for Speed

Security shouldn't slow you down. QRE Locker is built in Rust, a systems programming language known for blazing speed and memory safety.

By leveraging hardware acceleration (AES-NI) and efficient compression (Zstd), QRE Locker achieves encryption speeds that are often limited only by your disk's write speed. The Post-Quantum operations (Kyber) add negligible overhead, taking only milliseconds even on standard hardware.
